# شات بوت واتساب - مركز الزراعة (الهيئة الملكية لمحافظة العلا)

بوت مجاني بالكامل يعمل على جهازك محليًا عن طريق مسح رمز QR (نفس فكرة واتساب ويب)، بدون الحاجة لحساب Meta Developer أو أي رسوم.

## التشغيل

1. تأكد إن عندك Node.js مثبت (نسخة 18 فأعلى يفضل). تحقق بالأمر:
   ```
   node -v
   ```

2. ثبّت الاعتماديات:
   ```
   npm install
   ```

3. شغّل البوت:
   ```
   npm start
   ```

4. هيظهر لك رمز QR في التيرمنال. افتح واتساب على موبايلك (الرقم اللي هيرد على المزارعين) واعمل:
   الإعدادات > الأجهزة المرتبطة > ربط جهاز > امسح الرمز.

5. بعد ما يظهر "✅ البوت شغّال ومتصل بواتساب" البوت هيبدأ يرد تلقائيًا على أي رسالة توصل لرقم الواتساب ده.

> ملاحظة: لازم الجهاز اللي شغال عليه البوت (وموبايلك المربوط بيه) يفضلوا متصلين بالإنترنت طول الوقت عشان الردود تشتغل. لو قفلت الأمر أو الجهاز، البوت هيتوقف.

## تعديل الردود أو الرابط

كل النصوص والرابط موجودين في ملف [config.js](config.js) - عدّل فيه براحتك من غير ما تلمس [index.js](index.js).

خصوصًا لازم تحط رابط التسجيل الحقيقي بدل `"ضع رابط التسجيل هنا"` في أول سطر بالملف.

## مسار المحادثة الحالي

- **1** التسجيل في بطاقة المزرعة → يرسل رابط التسجيل ويرجع للقائمة.
- **2** التواصل مع موظف علاقات المزارعين → يرسل رسالة تحويل، وبعدها البوت **يتوقف عن الرد التلقائي** لهذا الشخص (لحد ما يكتب "قائمة" تاني).
- **3** الاقتراحات والشكاوى → يطلب البيانات، وأي رسالة تالية من المستخدم تعتبر ردّ بالبيانات ويشكره ويرجعه للقائمة.
- أي رقم غير صحيح → رسالة "لم نتمكن من التعرف على اختياركم" + القائمة تاني.
- كتابة "قائمة" في أي وقت → ترجع المستخدم للقائمة الرئيسية.

## إرسال رسالة جماعية (Broadcast) مع البوت شغّال في نفس الوقت

البوت الرئيسي (`npm start`) بيرد تلقائيًا على المزارعين **وفي نفس الوقت** بيراقب مجلد المشروع، فتقدر تبعت بث جماعي من غير ما توقفه أو تعمل مسح QR تاني.

1. البوت لازم يكون شغّال (`npm start`).
2. افتح [numbers.txt](numbers.txt) وحط كل رقم في سطر لوحده بصيغة دولية بدون + (مثال: `966501234567`).
3. افتح [message.txt](message.txt) واكتب نص الرسالة المطلوب إرسالها.
4. في تيرمنال تاني (نفس مجلد المشروع)، شغّل:
   ```
   npm run send-now
   ```
   ده بيعمل ملف صغير اسمه `SEND_NOW.txt`، والبوت بيكتشفه خلال ثانيتين ويبدأ يبعت البث تلقائيًا **من غير ما يوقف عن الرد على رسايل المزارعين**.
5. تابع التيرمنال اللي شغّال فيه البوت (`npm start`) هتشوف تقدم الإرسال رقم رقم مع علامة ✅/❌.
6. بعد ما يخلص، هتلاقي تقرير كامل في ملف `broadcast-log.txt`.

الإرسال بيتم واحد واحد بفاصل زمني عشوائي (4-9 ثواني) بين كل رقم والتاني عشان يقلل خطر حظر واتساب للرقم، وبيتجاهل أي رقم مش مسجل على واتساب.

### بديل: تشغيل البث لوحده بدون البوت

لو مش عايز تشغّل البوت الرئيسي أصلًا وعايز بس تبعت بث، استخدم:
```
npm run broadcast
```
(هيطلب مسح QR في أول مرة لو مفيش جلسة محفوظة مسبقًا).

> ⚠️ تنبيه: واتساب ممكن يحظر الأرقام اللي بتبعت رسائل جماعية كتير أو لأرقام مش حافظاك، خصوصًا لو الرسالة فيها روابط أو تتكرر بكثرة. استخدم الميزة دي بحرص ولأرقام مزارعين حقيقيين متعاملين مع المركز، ومش لأغراض ترويجية/سبام.

## الترقية لاحقًا (اختياري)

الحل ده تجريبي/محلي ومناسب للاختبار. للاستخدام الرسمي المستمر لاحقًا الأفضل:
- تشغيل البوت على سيرفر/VPS يفضل شغال 24 ساعة (بدل جهازك الشخصي).
- أو الانتقال لـ WhatsApp Cloud API الرسمي من Meta لثبات ودعم أفضل على المدى الطويل.
